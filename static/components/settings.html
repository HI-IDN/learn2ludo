Game rules

A player may move this many rolled sixes; after that, they do not roll again

If a player has no pawn in play, allow this many rolls to enter; recommended: 3
Safe squares

Equal number of rounds
After a player wins, continue until the first player would start the next round.
Continue after first winner

Board configuration

Number of yards
One yard per player; also sets the maximum number of players
Track length (fixed at 52)
Must be divisible by number of yards
Safe haven offset
Cells before the start cell that are also marked safe (default 7 = local position 2)
Home stretch length (fixed at 6)
Pawns per player
Number of pieces each player controls
Stack pawns in home stretch
First pawn takes the last space; next pawns fill the spaces before it
